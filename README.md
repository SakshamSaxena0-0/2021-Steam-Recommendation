# Steam Game Recommendation Model 
A machine learning-based recommendation system that suggests Steam games to users based on their past playtime and preferences.

## Features
Features

- Trains an SVD-based collaborative filtering model using Surprise
- Recommends games for users based on their play history
- Supports filtering by user ID or name
- Handles large datasets efficiently
- Efficient data preprocessing and model training
- Saves trained models for future use
- Includes a Jupyter Notebook for easy experimentation and visualization

## Usage
### Train The Model
**`training.py`** 
- This will preprocess the data, train the recommendation model, and save it.

### Ececute The Model
**`execution.py`**
- This will load the trained model and recommend games for a user.
